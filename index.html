操作说明

从订阅到连上的五步

  1. 对照流量、设备数与解锁需求选择基础版、旗舰版或团队版。
  2. 在官方用户中心完成订购后，复制 Clash 兼容订阅或通用订阅地址。
  3. 安装对应系统的客户端（见下一节官方下载原则）。
  4. 于客户端添加订阅 URL，更新节点，按延迟或用途筛选。

常见问题

溜冰猫(Skicat)是什么？和普通加速器有何不同？

溜冰猫是机场订阅服务：你得到的是节点列表与流量额度，客户端由自己安装。它强调可核对着的套餐参数、官方订阅入口和分场景线路，而不是一个打包不明的“一键加速器”。

如何完成机场订阅并导入客户端？

选择套餐后在官方面板复制订阅链接，打开已安装的 Clash 或其他客户端，选择“从 URL 添加订阅”并更新。导入成功后即可看到节点，按延迟排序后连接。不要使用来路不明的分享链接。

各套餐流量、设备与解锁分别是什么标准？

基础版每月 100GB、3 台设备、基础流媒体；旗舰版每月 300GB、5 台设备、全节点原生解锁与 IPLC 游戏优化；团队版每月 1000GB、20 台设备、高带宽节点与定制路由。流量按自然月重置。

客户端必须从哪里下载才算官方？

客户端属于第三方开源或商店应用，溜冰猫不提供 exe、apk 或 ipa 文件。请到对应项目的官方发布页或苹果、安卓应用商店下载。本页锚点“客户端下载”只解释原则，避免把仿冒包当成官网资源。

游戏卡顿或流媒体提示地区限制怎么办？

先切换至旗舰/团队的解锁或 IPLC 节点，关闭全局代理改用规则分流，并检查设备是否占用了套餐在线名额。若仍失败，通过旗舰优先工单或团队客户经理反馈节点名称与错误截图中的文字信息。

设备超限、流量用尽或需要改套餐如何处理？

超限时先下线不用的终端。流量用尽可等待重置或升级到更高档。改套餐在官方面板操作，年付与月付的差价规则以面板展示为准。团队版如需定制路由，联系专属客户经理说明网段与分流目标。
